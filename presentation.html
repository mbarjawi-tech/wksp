The primitive: git worktrees

Built into git since v2.5 — wksp makes them effortless across every repo in your project

One git database — two working directories — two branches
/c/dev/backend/ ← base clone, on main
acme/tasks/PROJ-1234/worktrees/backend/ ← worktree, on feature/PROJ-1234
acme/tasks/PROJ-5678/worktrees/backend/ ← worktree, on feature/PROJ-5678

# All three share the same .git object database
# Checkout is instant — no duplicate history on disk
wksp automates creating, naming, and tearing down worktrees across every repo in your project simultaneously — so you get all the power without ever typing git worktree add directly.

Setting up a project

One-time setup per product area — takes under a minute

Terminal
wksp init acme
✓ Created acme/

cd acme
wksp repo /c/dev/backend
wksp repo /c/dev/frontend
wksp repo /c/dev/services
wksp repo /c/dev/company-docs --shared
✓ 4 repos registered
🌿
Worktree repos
Each task gets its own isolated branch checkout. The default for repos you change.
📖
--shared repos
Read-only reference repos — docs, design systems. Always use the base folder, no branch management needed.
🔗
GitHub URLs work too
wksp repo https://github.com/org/repo — clones if needed, then registers.

Archive: done for now, not forever

Preserve context and branch metadata. Restore months later — even if branches were merged.

Archive
wksp task PROJ-1234 --archive

Removing worktrees...
✓ backend
✓ frontend
Writing archived.json...
✓ Moved → archived-tasks/PROJ-1234
Unarchive (3 months later)
wksp task PROJ-1234 --unarchive

Classifying branches...
backend present-local → worktree
frontend merged        → task-shared

Apply? [y/N]: y
✓ Restored PROJ-1234

wksp records each branch's tip SHA at archive time. On unarchive it checks: is the branch still local? merged into main? deleted but SHA reachable? It picks a sensible default for each repo and shows you a preview when anything non-trivial happened.

Key commands

CommandWhat it does
wksp init acmeCreate a project folder
wksp repo <path> [--shared]Register a repo (local path or GitHub URL)
wksp task PROJ-1234Create or resume — prompts for branches, launches Claude
wksp task PROJ-1234 --delTear down worktrees and delete the task folder
wksp task PROJ-1234 --archiveRemove worktrees, preserve context in archived-tasks/
wksp task PROJ-1234 --unarchiveRestore — smart branch recovery included
wksp task PROJ-1234 --to-shared backendUse base repo instead of worktree (this task only)
wksp task PROJ-1234 --to-worktree backendCreate a worktree; clears shared or excluded
wksp list --allLive and archived tasks in one view

Three commands to be up and running

# 2. Create your project
